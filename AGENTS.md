# Game mods workspace

These rules apply to all mods in this workspace.

1. Support hot reload in development builds. Keep hot reload out of release builds.
2. Give players an on/off toggle and an intensity control for every mod feature. For a third-person camera, provide a field-of-view slider.
3. Reuse the game's assets and native UI controls wherever practical.
4. Before implementing a new mod or visual change, present several concept sketches and wait for the user to select or approve a design.

## Gunfire Reborn compatibility

Target the current public Steam build. Verify the Mods Core loader, Mods tab, toggle, and slider on each new public build before marking it compatible. Complete this baseline on the current public build before implementing Centered Chase.
