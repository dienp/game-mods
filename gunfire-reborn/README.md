# Gunfire Reborn

- [Mods Core](mods/core/README.md) provides the shared Mods settings tab and a loader and settings probe.
- [Steady Third Person](mods/steady-third-person/README.md) adds a toggleable over-the-shoulder camera for a working BepInEx 6 IL2CPP install.

Each mod under `mods/` has its own Nx library and build target.

The combined release contains both plugins. Install BepInEx 6 IL2CPP x64 with metadata matching your Steam build, then extract the ZIP into the Gunfire Reborn install folder. Both DLLs go in `BepInEx/plugins`. The release notes list the tested game and loader builds. [Gunfire Reborn releases](https://github.com/dienp/game-mods/releases)
