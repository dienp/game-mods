# Endless Alice mods

This directory uses the root Nx workspace and npm lockfile. The game uses Unreal Engine and these mods run through [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v4.0.0).

| Mod | Nx project |
| --- | --- |
| [Primary Fire Homing](mods/primary-fire-homing/README.md) | `endless-alice-primary-fire-homing` |
| [Achievement Unlock](mods/achievement-unlock/README.md) | `endless-alice-achievement-unlock` |

## Release

The release includes both standalone mod ZIPs and a fresh-install bundle with UE4SS 4.0.0. Install the same Primary Fire Homing version on the host and guests for co-op. [Endless Alice Mods v1.0.2](https://github.com/dienp/game-mods/releases/tag/endless-alice-v1.0.2)
